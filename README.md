# backendTELEPIZZA

Backend de um sistema de pedidos para pizzaria, desenvolvido como **Trabalho Final da disciplina de Fundamentos de Desenvolvimento de Software (FDS)** — PUCRS.

## Tecnologias

- **Java 17+**
- **Maven** — build e gerenciamento de dependências
- **Spring Boot** — API REST

## Estrutura do projeto

```
backendTELEPIZZA/
├── src/
│   ├── main/java/        # código-fonte (controllers, services, models, repositories)
│   └── test/java/        # testes automatizados
├── docs/                 # diagramas e artefatos da disciplina
└── pom.xml
```

## Gestão do projeto

Os requisitos do trabalho são gerenciados via [Issues](https://github.com/bernardohlg/backendTELEPIZZA/issues) e acompanhados no board do projeto.
